# Addons Odoo 19

Déposer ici les addons compatibles avec Odoo 19.

- Un dossier de module par addon.
- Version du manifeste : `19.0.x.y.z`.
- Vérifier la compatibilité sur une instance Odoo 19 avant publication.
- Les règles d’accès et les fichiers de données doivent être déclarés dans le manifeste.
