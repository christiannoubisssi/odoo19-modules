# Addons Odoo 19

Déposer ici un dossier par addon compatible avec Odoo 19. Chaque dossier installable doit contenir au minimum `__init__.py` et `__manifest__.py`.

`module_template/` est un squelette à copier et renommer; ne pas l’installer tel quel. La version du manifeste doit suivre la forme `19.0.x.y.z`. Documenter les dépendances et les tests de compatibilité dans le README de chaque module.
